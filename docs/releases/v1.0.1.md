# Property Value Insights v1.0.1

## Escopo

Release final de entrega após o encerramento das Reviews #34–#39 e da
consolidação #33. A versão organiza o repositório, atualiza a apresentação e
publica a imagem Docker sem alterar o modelo, o artefato ou o contrato da API.

## Identidade

- projeto: `1.0.1`;
- API: `0.5.0-rc1`;
- modelo: `property_value_hist_gradient_boosting_physical 0.4.0-rc1`;
- artefato SHA-256: `90ffbab62970c805b7fd65a5488fa727026bdc59b81d56726318374cdce8c439`;
- imagem: `ghcr.io/umbura/property-value-insights:1.0.1`.

## Lapidação

- `CONTEXTO_DESAFIO.md`, `ESTRATEGIA_EXECUCAO.md` e `PROCESSO_GIT_GITHUB.md`
  movidos para `docs/process/`;
- `PESQUISA_DIFERENCIAIS.md` movido para `docs/archive/`;
- `.gitkeep` removidos de `artifacts/` e `diagrams/`, que já possuem conteúdo;
- `AGENTS.md` preservado na raiz por aplicar regras a toda a árvore;
- evidências, notebooks, dados, relatórios e contratos preservados.

## Publicação

A GitHub Release `v1.0.1` aciona `.github/workflows/release.yml`. O workflow
confere a correspondência da tag com o pacote, constrói e publica a imagem com
labels OCI e valida `/health`, `/model-info`, `/metrics` e `/predict` usando o
digest publicado.

#70 não fazem parte desta release. Consulte o model card e a consolidação do
Ciclo 1 antes de uso consequencial.
